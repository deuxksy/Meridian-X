# Meridian-X OKF (Open Knowledge Framework)

사람(개발자, 운영자) 중심의 공식 지식 프레임워크 허브입니다. 모든 프로젝트 지식은 [Diátaxis](https://diataxis.fr/) 4분면 구조에 따라 체계적으로 분류되어 관리됩니다.
