# Meridian-X Documentation Hub

Meridian-X 프로젝트의 통합 문서 허브입니다. 모든 문서는 목적과 독자에 따라 명확하게 분리되어 관리됩니다.

---

## 📁 주요 문서 영역 안내

```text
docs/
├── README.md                  # 본 문서 (전체 Documentation Hub)
├── okf/                       # 📖 사람이 읽는 공식 지식 프레임워크 (OKF Hub)
│   ├── README.md              # OKF Diátaxis 4분면 메인 인덱스
│   ├── tutorials/             # 1. Tutorials (입문 및 첫 실행)
│   ├── how-to/                # 2. How-To Guides (운영 가이드)
│   ├── reference/             # 3. Reference (설정/CLI 명세)
│   └── explanation/           # 4. Explanation (아키텍처/설계 결정)
├── archive/                   # 🗄️ 비관리형 과거 기획안 및 참조 자료 아카이브
└── superpowers/               # 🤖 AI 코딩 에이전트 전용 명세(specs/) 및 계획서(plans/)
```
